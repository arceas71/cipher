📦 How to Install on Phone & Laptop

1. Push the repository package files to github.com/arceas71/jarvis 2. Open your repo on GitHub -> click the "Actions" tab at the top. 3. Select "Build JARVIS Android APK & Deploy Web OS" on the left -> click "Run workflow". 4. Once finished (~2 mins), scroll to "Artifacts" at the bottom of the run summary and download "jarvis-android-apk" (contains jarvis-debug.apk for your phone). 5. On laptop or iOS/Android browser, open your GitHub Pages link or run index.html directly!
